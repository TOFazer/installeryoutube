# ⚡ OverLoad

Application web (Flask + yt-dlp) pour télécharger des vidéos YouTube en vidéo (meilleure qualité) ou en MP3.

## Installation
```bash
pip install -r requirements.txt
```
⚠️ [FFmpeg](https://ffmpeg.org/download.html) doit être installé (fusion vidéo/audio et conversion MP3).

## Lancement
```bash
python app.py
```
Puis ouvre http://localhost:5000
