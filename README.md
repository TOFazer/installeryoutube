# ⚡ OverLoad

Application de bureau pour télécharger des vidéos YouTube en **vidéo (meilleure qualité)** ou en **MP3**.
Interface moderne (CustomTkinter), barre de progression, vitesse, miniature, choix du dossier.
FFmpeg est inclus automatiquement (via `imageio-ffmpeg`), rien à installer à part.

## 📥 Installer (Windows, sans Python)
Va dans l'onglet **Actions** du dépôt GitHub → dernier build → télécharge **OverLoad-Windows** → lance `OverLoad.exe`.

## 🛠️ Construire le .exe toi-même
Double-clique sur `build.bat` → l'app est créée dans `dist\OverLoad.exe`.

## ▶️ Lancer depuis Python
```bash
pip install -r requirements.txt
python overload.py
```
