# Contribuer à OverLoad

1. Forke le dépôt et crée une branche.
2. `pip install -r requirements-dev.txt`
3. Code, puis `python -m pytest`. Tous les tests doivent passer.
4. Ouvre une Pull Request en expliquant **pourquoi** tu fais ce changement.

**Règles :** pas de télémétrie cachée, pas de publicité, pas de contournement de DRM. Toute affirmation
de performance doit s'appuyer sur `scripts/benchmark.py`.

**Signaler un bug :** indique ta version d'OverLoad, ta version de Windows, le lien utilisé (s'il est public)
et le message d'erreur.
