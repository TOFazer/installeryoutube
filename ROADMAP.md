# Roadmap OverLoad

## Phase 1 — Prouver la vitesse ✅ (v0.1)
- [x] Moteur yt-dlp, connexions parallèles adaptatives
- [x] Mesure de la vitesse réelle, script de benchmark reproductible (médiane, CSV)
- [ ] Publier les premiers résultats de benchmark (mesures réelles uniquement)

## Phase 2 — Construire l'application ✅ (v0.2 → v0.4)
- [x] Interface, analyse, choix de la qualité, progression
- [x] Mode Monteur : projets, file d'attente, historique
- [x] Simultanés, reprise, erreurs réseau, intégrité

## Phase 3 — Tester et publier (v1.0)
- [x] Installateur Windows, portable, SHA-256, CI
- [ ] Tests sur un PC Windows propre (10 et 11)
- [ ] Signature de code (supprime l'avertissement SmartScreen)
- [ ] Tests utilisateurs avec des monteurs

## Phase 4 — Faire connaître OverLoad
- [ ] Site de présentation (GitHub Pages, `docs/`)
- [ ] Démos vidéo (Shorts / TikTok) et captures
- [ ] Communautés montage et tech, retours utilisateurs

## Plus tard
